⚠️ Google Maps API Key Diperlukan

Untuk menampilkan Google Maps secara penuh, ikuti langkah berikut (gratis, 5 menit):
  1. Buka console.cloud.google.com
  2. Buat project baru → Aktifkan "Maps JavaScript API"
  3. Buka Credentials → Create Credentials → API Key
  4. Salin kunci (contoh: AIzaSyXXXXXXXX...)
  5. Buka file .env di project Anda, ubah baris:
    GOOGLE_MAPS_KEY=AIzaSyXXXXXXXX...
  6. Restart server, lalu refresh halaman ini.
